# 📊 Sorting Algorithm Visualizer

An **interactive and responsive Sorting Algorithm Visualizer** built using **HTML, CSS, and JavaScript**.  
This project helps learners **see, hear, and understand** how popular sorting algorithms work step by step.

---

## 🚀 Live Features

✨ Visual Sorting Animation  
🎵 Sound effects mapped to values  
⚡ Speed control (slow → fast)  
🔁 Multiple sorting algorithms  
🎨 Switch between Box & Bar view  
📱 Fully responsive (mobile friendly)

---

## 🧠 Algorithms Implemented

- 🫧 Bubble Sort  
- 🎯 Selection Sort  
- 🧩 Insertion Sort  
- 🌲 Merge Sort  
- ⚡ Quick Sort  
- 🧠 Tim Sort (JavaScript built-in)

---

## 🖥️ How It Works

1. Enter numbers separated by **commas or spaces**
2. Click **Set Array**
3. Choose a **sorting algorithm**
4. Adjust the **speed slider**
5. Watch the algorithm sort visually with sound 🎶

---

## 🎨 Visualization Modes

- **Box Mode** – Displays numbers inside colorful boxes  
- **Bar Mode** – Displays values as height-scaled bars  

👉 Switch instantly using the **“Switch Style”** button.
